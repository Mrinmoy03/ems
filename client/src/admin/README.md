# WorkTrack Admin Module

## Status: Placeholder (Future Scope)

This directory is designated for the Admin portal and management interfaces. In this initial phase, only the **Employee Module** (`src/employee/`) is implemented.

### Planned Admin Features:
- Employee account provisioning (first name, last name, designation, department).
- Task assignment to one or more employees with deadlines.
- Deadline and priority adjustments with audit reasons.
- Review of daily End-of-Day (EOD) and monthly employee performance reports.
- Real-time attendance and present-day employee tracking.
- Task progress overview and performance analytics across teams.
